# ADR-0007: Release-approved deployment transaction

## Context / 背景

The user selected configured deployment commands, but partial deployment and
verification failure must not be represented as success.

## Decision / 決定

Model completion as deploy, verify, and rollback commands. Require current
readiness and release approval, reject incomplete configuration, retain bounded
command provenance, and invoke rollback exactly once after deploy or verify
failure.

## Rejected alternatives / 却下案

- Deploy immediately when QA first reports readiness: rejected because release
  approval remains mandatory.
- Provider-specific cloud code in v1: rejected because the selected adapter is
  generic configured commands.

## Consequences / 結果

Provider behavior is delegated to reviewed commands. Terminal status clearly
distinguishes deployed, recovered, and rollback-failed outcomes.
